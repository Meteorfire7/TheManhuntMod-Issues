# The Manhunt Mod: bug reports and suggestions

This repository is only for **bug reports and feature requests** for [The Manhunt Mod](https://modrinth.com/mod/the-manhunt-mod), a Fabric mod for Minecraft that adds a manhunt game mode with a hunter tracking compass and role management.

The source code is not published here. The mod is distributed under an **All Rights Reserved** license, see the [LICENSE](LICENSE) file for what you can and cannot do.

## Found a bug?

1. Open the [Issues](../../issues) tab and click **New issue**.
2. Choose **Bug report** and fill in the form.
3. Attach your `latest.log` (or a link to it, for example from [mclo.gs](https://mclo.gs)). Reports with a log are much easier to fix.

## Have an idea?

Choose **Feature request** when opening a new issue.

## Download

Releases are published on [Modrinth](https://modrinth.com/mod/the-manhunt-mod).
